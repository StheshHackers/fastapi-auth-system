# FastAPI Authentication System

This is a basic authentication system that built in Python's FastAPI library.
This cannot do much, but you can tamper it and make it your app's authentication system.
This serves as a boilerplate for your app's authentication, such that you do not need to write authentication logic from sratch.

## Please note that this project promotes the Stheshana Developers society.

## How to use

1. Clone this github repository (`git clone https://github.com/StheshHackers/fastapi-auth-system.git`)
2. Install all the requirements of this project (`pip install -r requirements.txt`)
3. Create a .env file in the root of this and add a key name DB_URL
4. Fire the project up with `uvicorn app.main:app` or ```python -m uvicorn app.main:app```
5. Once the app is running you can start sending requests back and forth.
6. Edit the source code as much as you like until it becomes what you want it to be
